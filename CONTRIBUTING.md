# Contributing to IconVault

Thanks for contributing. IconVault is intentionally simple: place icon files directly in `icons/` and use clear filenames. No package installation or build step is required.

## Submit an icon

Before opening a pull request, check that the icon is valid, give it a descriptive filename, and include the original source and license. Keep required attribution with the submission. Do not submit files if redistribution rights are unclear.

## Pull requests

Keep changes focused. Say which files you added or changed, provide the source and license, and confirm that you checked the icon renders correctly.
